# Contributing

## Issues

Open an issue from the [issue chooser](https://github.com/InSearchOfName/Book-Writer/issues/new/choose). There are templates for:

- **Bug report**: include the Minecraft version, mod version and logs
- **Minecraft version update**: the dependency table and checklist for moving to a new Minecraft version
- **Feature request**: what you'd like and why

Anything else can be opened as a blank issue.

## Pull requests

Start from the issue's branch (for example `31-issue-templates`) and describe the change in the pull request, with `Closes #N` for the issue it resolves. See [RELEASING.md](RELEASING.md) for branch and release naming.
